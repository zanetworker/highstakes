## Caveats

- PR labels follow each project's habits; where PRs are rarely labelled, bug fixes rest on `fix:` titles.
- Review depth and CODEOWNERS reflect maintainer judgment of importance, but also code volume and activity. Read each stakes row next to `pr_activity`.
- Repos that hit the 1,500-PR cap are missing the oldest part of the 365-day window.
- Backports need remote release branches in the clone; branch names matching the rule are not always real backport lines.
- Blast radius, complexity and centrality come from today's file contents even in holdout mode.
